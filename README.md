## Username, имя и Telegram ID — в чём разница

- Username — уникальное на текущий момент имя с `@`, которое владелец может изменить.
- Отображаемое имя — подпись профиля, которая может повторяться у множества людей.
- Telegram ID — числовой идентификатор аккаунта.
- Ссылка на профиль обычно содержит актуальный username, но может перестать работать после переименования.
